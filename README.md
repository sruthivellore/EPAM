# EPAM Java Practice Repository

Welcome to the **EPAM Java Practice Repository**!  
This project is a curated collection of Java programming exercises and solutions, organized by topic and difficulty. It’s perfect for anyone looking to practice core Java concepts, algorithms, and get hands-on experience with Maven.

---

## 📚 Repository Overview

This repository is divided into several tasks and modules, each focusing on a particular Java topic or coding challenge:

### 1. Epam_Task2

**Location:** `Epam_Task2/`

- Contains Java files for Task 2.
- **Topics covered:**  
  - Basic Java programming
  - Input/output handling
  - Control structures (if/else, loops)
- **How to use:**  
  Open the Java files in this folder to review and run solutions for the second set of EPAM practice tasks.

---

### 2. Epam_Task3

**Location:** `Epam_Task3/src/task3/`

- Contains Java files for Task 3.
- **Topics covered:**  
  - Arrays and array manipulation
  - Sorting algorithms
  - Searching algorithms
  - Possibly small utility classes
- **How to use:**  
  Each Java file in this folder typically solves a specific algorithmic problem. Open the file and run the `main` method to see the solution in action.

---

### 3. Epam_Task4

**Location:** `Epam_Task4/`

- Contains Java files for Task 4.
- **Topics covered:**  
  - Object-Oriented Programming (OOP)
  - Classes and objects
  - Inheritance, polymorphism, encapsulation
  - Real-world modeling with Java classes
- **How to use:**  
  Explore the Java files to see examples of OOP in action. You can run the `main` methods to test the behavior of the classes and their relationships.

---

### 4. Epam_Task5

**Location:** `Epam_Task5/`

- Contains Java files for Task 5.
- **Topics covered:**  
  - Advanced Java concepts
  - Collections framework (ArrayList, HashMap, etc.)
  - Exception handling
  - File I/O and serialization
- **How to use:**  
  These files demonstrate more advanced Java programming. Review the code to see practical examples of using collections, handling exceptions, and working with files.

---

### 5. maven_sample

**Location:** `maven_sample/`

- A sample Maven project to help you learn about Maven structure and dependency management.
- **Topics covered:**  
  - Maven project setup (`pom.xml`)
  - Organizing code with Maven conventions (`src/main/java`, `src/test/java`)
  - Managing dependencies and plugins
- **How to use:**  
  Open this folder as a Maven project in your IDE. Run Maven commands like `mvn compile` or `mvn test` to build and test the project.

---

### 6. Mergesort.java

**Location:** `Mergesort.java` (in the root directory)

- A standalone Java file implementing the Merge Sort algorithm.
- **Topics covered:**  
  - Divide and conquer algorithms
  - Sorting
  - Recursion
- **How to use:**  
  Compile and run this file to see how Merge Sort works in Java.
